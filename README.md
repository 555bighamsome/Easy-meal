# Easy Meal - 智能菜谱与采购清单小程序

> 从"今天吃什么"到"一键购齐"，你的美食生活助手

## ✨ 核心特色

### 🎯 智能心情选择
根据你的心情推荐适合的菜谱：
- 😌 需要被治愈 → 温暖的汤品
- 🎉 想要庆祝 → 硬菜大菜
- 😫 累到爆炸 → 15分钟快手菜
- 🥰 想做给TA吃 → 用心料理
- 😋 就是想吃好的 → 美味菜肴
- 💪 健康减脂中 → 低卡高蛋白

### 🛒 一键生成采购清单（核心创新！）

这是我们的**杀手锏功能**，完全超越传统菜谱App：

1. **智能合并食材**
   - 自动合并多个菜谱的相同食材
   - 例如：3道菜都要鸡蛋，自动累加为6个

2. **智能优化建议**
   - 鸡蛋5个 → 建议买6个（一盒装）
   - 检测家里库存，避免重复购买

3. **多平台价格对比**（核心亮点！）
   - 实时对比盒马、美团买菜、拼多多等平台价格
   - 智能推荐最优购买方案：
     - 🥇 **推荐方案**：新鲜食材30分钟达（盒马）+ 调料次日达（拼多多）
     - ⚡ **极速方案**：全部30分钟送达，多花¥5
     - 💰 **省钱方案**：全部拼多多购买，节省¥12

4. **一键跳转购买**
   - 直接跳转到电商小程序
   - 预填充购物车
   - 无缝购买体验

## 📱 技术栈

- **框架**: Taro 3.6 (React + TypeScript)
- **平台**: 微信小程序 (可扩展到其他平台)
- **样式**: SCSS + 自定义设计系统
- **状态管理**: React Hooks
- **数据**: 本地模拟数据 (可对接真实API)

// 1. 提取所有菜谱的食材
const ingredients = extractIngredients(recipes);

// 2. 智能合并相同食材（自动累加数量）
const merged = mergeIngredients(ingredients);

// 3. 检查用户库存
const filtered = checkUserInventory(merged);

// 4. 智能优化建议
const optimized = suggestOptimizations(filtered);
